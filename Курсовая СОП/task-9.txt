
Вариант №9

Создать вычислительный кластер из 3 узлов, где 1 мастер и 2 воркера, являющиxcя отдельными физическими серверами (или виртуальными машинами),
в котором:
- мастер узел и имеет политику отказоустойчивости "автовостановление через N попыток"
- первый узел с воркерами имеет политику отказоустойчивости для сервисов: "репликация с нечетным количеством копий"
- второй узел с воркерами имеет политику отказоустойчивости для сервисов: "автовостановление через N попыток"

Стратегия обновления сервисов в кластере должна соответствовать политике:
- допускается простой сервиса
- без смешивания версий
- с откатом в случае сбоя при обновлении

Функциональные требования к сервисам:
На первом узле:
- каждый сервис имеет свой отдельный слой данных, к которому он обращается в виде: тома
На втором узле:
- все сервисы имеют единый слой данных, к которому они обращаются в виде: базы данных

Инфраструктура кластера должна обеспечивать функции (задания на оценки 4 и 5):
- на 4: Централизованный сбор телеметрии c сервисом визуализации для простора
- на 5: В кластере должен присутствовать: "Сервер конфигураций (сервисы должны получать конфигурации для запуска только с него)" и взаимодействовать с кластером согласно схеме
